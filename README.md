# Мероприятия ПГУ

Приложение для Android со списком мероприятий ПГУ им. Т.Г. Шевченко. Студент входит через Google, выбирает филиал, кафедру, направление и курс, отмечает избранное и участие. Администратор добавляет и удаляет мероприятия через сервер на компьютере.

## Как устроено

Внизу три раздела: **Главная**, **Избранное**, **Профиль**.

- На главной карточки мероприятий: тип, место, дата и время начала и окончания.
- Фильтр идёт по шагам: филиал, кафедра, направление, курс. Кнопка «Сохранить и показать» запоминает выбор для этого Google-аккаунта. При следующем входе тот же путь открывается сам.
- Звезда кладёт мероприятие в избранное. Это только закладка, без уведомления.
- «Я участвую» включает звуковое напоминание. Оно приходит только по таким мероприятиям. В профиле выбирается, за сколько предупредить: 15 минут, 30 минут, 1 час или 2 часа. По умолчанию 30 минут.
- Если адрес сервера в профиле пустой, список хранится на телефоне. Добавление и удаление администратора тогда видны только на этом устройстве.

## Запуск на телефоне

Нужны Flutter и телефон с включённой отладкой по USB.

1. На телефоне: **Настройки → О телефоне**, семь раз нажать **Номер сборки**.
2. **Для разработчиков → Отладка по USB**.
3. Подключить кабель и подтвердить запрос на отладку.
4. На компьютере из корня проекта:

```powershell
cd D:\FlutterProjects\my_app
flutter devices
flutter run
```

В списке устройств должен быть телефон. Пока `flutter run` работает, в том же окне `r` обновляет приложение.

На Redmi и Xiaomi с HyperOS установка часто блокируется. В режиме разработчика включите **Отладка по USB (настройки безопасности)** и при появлении запроса на экране нажмите **Разрешить**. Телефон в этот момент должен быть разблокирован.

### Вход через Google

Без настройки Google Cloud кнопка «Войти через Google» завершится ошибкой. Пакет приложения: `com.example.my_app`.

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект.
2. На экране согласия OAuth укажите название и свою почту. Тип доступа — External.
3. Добавьте свой Gmail в тестовые пользователи. Пока приложение в режиме теста, войти может только эта почта.
4. Создайте клиент OAuth типа Android.
   - Package name: `com.example.my_app`
   - SHA-1 отладочного ключа этого компьютера:

```powershell
keytool -list -v -alias androiddebugkey -keystore "$env:USERPROFILE\.android\debug.keystore" -storepass android -keypass android
```

После сохранения клиента подождите несколько минут, полностью закройте приложение и снова выполните `flutter run`.

## Сервер мероприятий

Сервер — программа `tool/event_server.dart`. Она хранит общий список в `tool/data/events.json`. При первом запуске файл заполняется учебными мероприятиями. Добавлять и удалять записи может только приложение с правами администратора.

Запуск из корня проекта, отдельным окном. Это окно не закрывайте, пока телефоны должны видеть список:

```powershell
cd D:\FlutterProjects\my_app
dart run tool/event_server.dart
```

Сервер печатает адреса. Порт всегда `8080`.

| Где открыто приложение | Адрес в профиле |
| --- | --- |
| Эмулятор Android на этом компьютере | `http://10.0.2.2:8080` |
| Телефон в той же сети Wi‑Fi | `http://IP-компьютера:8080` — строка «Телефон в этой сети» в выводе сервера |
| Телефон только по USB-кабелю | `http://127.0.0.1:8080` после команды ниже |

Для кабеля без общей сети, во втором окне:

```powershell
adb reverse tcp:8080 tcp:8080
```

Дальше в приложении: **Профиль → Сервер мероприятий**, вставить адрес и нажать **Сохранить адрес**. Список подтягивается при открытии приложения и если потянуть главную вниз.

Пустой адрес снова переключает приложение на список, сохранённый на телефоне.

Если Windows спросит разрешение для порта 8080, разрешите его в частной сети.

## Вход как администратор

Сначала войдите через Google.

1. Откройте **Профиль**.
2. Нажмите **Войти как администратор**.
3. Введите код `pgu-admin`.

После этого внизу появляется **Добавить**, а в карточке мероприятия — **Удалить мероприятие**. Роль запоминается на этом телефоне для текущего Google-аккаунта. Снять её можно кнопкой **Снять права администратора**.

Код и список почт, которым роль выдаётся сразу без кода, лежат в `lib/config/app_config.dart`:

- `adminAccessCode` — код из профиля;
- `adminEmails` — Google-почты администраторов;
- `adminToken` — ключ, которым приложение подтверждает запись на сервере. Сервер читает то же значение. Менять его в интерфейсе не нужно. Если меняете код или ключ, меняйте их в этом файле и перезапускайте и приложение, и сервер.
